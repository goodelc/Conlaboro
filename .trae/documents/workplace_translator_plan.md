# 职场话术转换器优化计划

## 一、问题分析

### 1.1 核心需求
- 用户输入大白话（如："这个做不了"）
- 系统根据选择的风格（正式/委婉/幽默/政务）翻译为职场黑话
- 参考效果：输入"这个做不了" → 输出"该需求的实现目前面临一定的技术或资源壁垒 我们需要进一步的评估可行性，以保障最终交付质量，你看是否合适"

### 1.2 当前代码问题
1. `BANNED_WORDS` 应该是黑话词库，而非禁用词！这个命名是反的
2. Prompt 不够具体，缺少详细示例和指令
3. 风格指南只有一个示例，AI 难以准确理解
4. 缺少明确要求使用黑话词汇的指令
5. 正式风格的默认值是 '正式商务'，但 STYLE_GUIDES 里只有 '正式'

## 二、核心优化方案

### 2.1 黑话词库重构
- 重命名为 `JARGON_WORDS`（行话词汇）
- 保持词汇不变，但说明这是需要使用的词库

### 2.2 Prompt 大幅优化（核心！）
每个风格的 prompt 需要包含：
1. **风格特点说明** - 详细描述该风格的语气、感觉、适用场景
2. **黑话词库** - 明确列出，要求必须使用
3. **多个输入输出示例** - 至少 3-5 个，让 AI 准确理解
4. **明确的输出要求** - 字数、格式、必须使用黑话数量等

### 2.3 四种风格定位

| 风格 | 特点 | 黑话使用程度 |
|------|------|-------------|
| 正式 | 专业、严谨、不卑不亢 | ★★★★★ 大量使用 |
| 委婉 | 留有余地、商量语气 | ★★★ 适度使用 |
| 幽默 | 自嘲、调侃、轻松 | ★★ 点缀使用 |
| 政务 | 公文体、四字短语 | ★★★★ 特定词汇 |

## 三、详细修改内容

### 修改 1：修正命名和默认值
- `BANNED_WORDS` → `JARGON_WORDS`
- 默认风格从 '正式商务' 改为 '正式'

### 修改 2：重写 `STYLE_GUIDES`
为每个风格提供详细的描述和多个示例

### 修改 3：完全重写 `PROMPTS.translate`
这是最重要的修改！新的 prompt 结构：
```
【角色定位】
【风格特点】
【黑话词库】（必须使用至少 X 个）
【输入输出示例】（3-5 个）
【输出要求】
```

## 四、优化后的代码结构示意

```typescript
// 黑话词库 - 这些是要使用的，不是禁用的！
const JARGON_WORDS = '赋能、颗粒度、对齐、带宽、业务吞吐量、交付质量、沉淀、抓手、闭环、心智、底层逻辑、范式、矩阵、链路、复用、迭代、耦合、解耦、维度、阈值、复盘、聚焦、协同、打通、拉通、落地、承接、支撑、响应、感知、洞察、驱动、牵引、倒逼、击穿、穿透、引爆、裂变、生态、护城河、壁垒';

// 风格指南 - 大幅扩展
const STYLE_GUIDES: Record<string, string> = {
  '正式': `【正式风格】
特点：专业严谨、不卑不亢、显得经过深思熟虑
黑话要求：必须大量使用黑话词库中的词汇（至少 5 个）
示例：
- "我真的顶不住了" → "目前工作负荷较大，建议对任务优先级进行重新梳理对齐，确保核心业务交付质量"
- "这个做不了" → "该需求的实现目前面临一定的技术或资源壁垒，我们需要进一步评估可行性，以保障最终交付质量，你看是否合适？"
- "我没时间" → "当前带宽有限，建议重新对齐优先级，聚焦核心链路"`,
  
  '委婉': `【委婉风格】
特点：商量语气、留有余地、不得罪人
黑话要求：适度使用（2-3 个）
示例：...`,
  
  // ... 其他风格
};

// Prompt 完全重写
const PROMPTS = {
  translate: (style: string) => {
    const guide = STYLE_GUIDES[style] || STYLE_GUIDES['正式'];
    return `你是一个专业的职场话术转换器。用户输入一句大白话，你把它翻译成${style}风格的职场黑话版本。

${guide}

【黑话词库】（必须从中选用词汇）：${JARGON_WORDS}

【严格要求】
1. 必须使用上述黑话词库中的词汇！正式风格至少用 5 个，其他风格至少用 2-3 个
2. 只输出一条翻译结果，不要输出多个版本或备选
3. 一句话，简洁有力，30-80 字
4. 纯文本输出，严禁 markdown 符号
5. 直接输出翻译结果，不要任何前缀说明或标题
6. 语义要与原文一致，只是表达方式更职场化`;
  },
  // ...
};
```

## 五、关键改进点总结

1. ✅ **改名**：`BANNED_WORDS` → `JARGON_WORDS`，语义明确
2. ✅ **多示例**：每个风格提供 3-5 个输入输出对
3. ✅ **强制要求**：明确指定必须使用黑话的数量
4. ✅ **详细描述**：说明每种风格的语气、感觉、适用场景
5. ✅ **修正默认值**：默认风格与 STYLE_GUIDES 一致
